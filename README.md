<h1>Site para Barbearia</h1>

<h2>Site institucional para uma Barbearia, construída 100% com HTML, CSS e JavaScript puros.</h2>

<h3>🎯 Sobre o Projeto</h3>
<p>O layout é limpo, com design atraente, navegação clara e hierarquia de conteúdo bem definida — cada seção tem um propósito (Início, Serviços, Sobre, Galeria e Contato), o que melhora tanto a experiência do usuário quanto a compreensão semântica do site.

A estrutura HTML segue boas práticas de semântica, usando elementos que facilitam a leitura de buscadores e a acessibilidade, além de separar claramente conteúdo e estilo com CSS externo. Além disso, a utilização de JavaScript adiciona interatividade leve sem comprometer a performance.</p>

<h3>🔧 Tecnologias Utilizadas</h3>

<p>✅ HTML5 Semântico</p>
<p>✅ JavaScript</p>
<p>✅ CSS3 (Grid, Flexbox)</p>

<h3>🎯 Destaques do Projeto:</h3>

<p>✅ Menu fixo (e hamburguer no mobile) com links para seções (Início, Serviços, Sobre, Galeria, Contato),</p>
<p>✅ Conteúdo organizado em blocos claros,</p>
<p>✅ Tipografia legível e hierarquia de títulos (importante pra acessibilidade/SEO)</p>
<p>✅ Design Responsivo (Mobile-First)</p>
<p>✅ Animações CSS e Transições</p>
<p>✅ Estilo totalmente separado em CSS, e JS leve pra melhorar a experiência do usuário.</p>
